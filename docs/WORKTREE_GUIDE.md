# Рабочие папки двух исполнителей

Актуально: капитан/backend и один frontend на разных компьютерах. Капитан продолжает в исходном checkout на codex/api-integration. Тиммейт уже настроил nomad-web на codex/web-ui и открыл её в Codex Local. Повторно создавать worktree не нужно. GitHub передаёт коммиты, а не историю разговора или незакоммиченные файлы.

После публикации капитаном каркаса тиммейт выполняет в nomad-web по одной команде:

```powershell
git status --short --branch
git fetch origin
git merge origin/main
```

Если status показывает изменения — сначала сохранить их своим коммитом либо передать вывод капитану. При ошибке merge остановиться, не применять --force и не удалять папки.

Далее из этой же папки выполнить setup и запуск по README. Прочитать docs/TEAM.md, docs/TASK_WEB.md и contracts/README.md. Изменять frontend, не менять общие генерируемые типы. На компьютерах команды Python 3.12, Node 22.12+ (проверенная версия капитана указана в .node-version).

Результат отдавать через коммит и push в codex/web-ui, сообщать капитану SHA, команды проверок и ограничения. main объединяет только капитан. Папка nomad-data и дополнительный worktree больше не требуются.
