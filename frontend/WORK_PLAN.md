## Context and Orientation

frontend/src/App.tsx управляет состоянием и переходами, а страницы находятся в frontend/src/pages/. src/api/client.ts обращается к FastAPI и использует общие типы src/api/generated/schema.d.ts. Сервер хранит версии заказов; expected_revision защищает от перезаписи чужих изменений. contracts/README.md описывает API. Демо возвращает 144, 0, null, импорт и реальный расчёт пока отвечают 501. Схемы и backend принадлежат капитану.

## Plan of Work

Первый этап: выделить страницы DataPage, RecommendationsPage, OrderPage и ExplanationPanel, общие подписи и ошибки. App управляет загрузкой и переходами. CSS использует заданные цвета и адаптивную таблицу. Существующий браузерный сценарий должен проходить после оформления.

Второй этап: формы настроек и файлов, поиск и фильтры, пагинация 50/100, сохранение выбора, подробное объяснение с ленивым графиком. Заказ хранится на сервере, CSV загружается как файл с обработкой ошибок. Панель удерживает фокус, закрывается Escape и возвращает фокус. Ошибка 409 сохраняет правки до явного отказа от них.

## Concrete Steps

Из корня выполнить `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1 -Browser`. Команда запускает backend-проверки, сборку и Chromium через FastAPI на свободном порту 8009. При исправлениях frontend повторять сборку и `npm --prefix frontend run test:e2e`. Снимки сохраняются в frontend/test-results. Окружения .venv и node_modules уже существуют.

## Validation and Acceptance

Проверить 144/0/null, блокировку неизвестного количества, фильтры и выбор одного поставщика, обязательную причину, нулевую правку после refresh, согласование и содержимое CSV. После изменения согласование снимается. Явные тестовые ответы проверяют 409, 501 и сетевые ошибки. Проверить 1366×768, 1440×900, 768 и 390 px: страница не имеет горизонтального переполнения, таблица прокручивается внутри. Проверить Escape и возврат фокуса панели.

## Idempotence and Recovery

Проверки используют отдельную временную базу. Исходные данные не нужны. Повторный запуск безопасен. Не удалять чужие файлы, не менять main, не генерировать схемы. Git worktree хранит служебные файлы вне разрешённой папки, для операций Git может потребоваться расширение доступа.

## Interfaces and Dependencies

Использовать имеющиеся React, TypeScript, Recharts, Vite и Playwright. Новые библиотеки не требуются. Все HTTP-запросы остаются в src/api/client.ts. Формы используют существующий CalculationSettings; объяснение использует только ItemExplanation.
